# Assinatura Nexu no GitHub Pages

Esta pasta deve ser publicada no GitHub Pages. Depois de publicada, abra o link `https://...github.io/.../` e use o botao `Copiar assinatura`.

Por que funciona melhor que Drive:

- O GitHub Pages entrega arquivos como site publico HTTPS.
- As imagens em `assets/` ficam com URLs diretas.
- O HTML copiado para Gmail/Outlook fica curto e usa os assets originais.

Arquivos:

- `index.html`: gerador da assinatura.
- `assets/`: fundo, logo, wordmark e icones.
